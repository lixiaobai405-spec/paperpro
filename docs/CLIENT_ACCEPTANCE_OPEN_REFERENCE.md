## 外部公开 PDF 固定挑战集：首轮与修复后复测

源：jijunhao/SyntheticResumeData
固定 Git commit：3ecd09129f65955e743aacf67f2785fcee10d461
固定文件编号：1–10、101–105、201–205，共 20 个外部合成 PDF，分别使用相应的人工核对 GT JSON。
测量脚本：scripts/benchmark_external_resume_corpus.py
运行：uv run --python 3.12 python -m scripts.benchmark_external_resume_corpus

文件在内存中通过固定版本 Git 对象或 GitHub API 取得、解析、校验 SHA256；按需读取的外部 Git 对象缓存在操作系统临时目录（不属于 PaperPro 项目或版本库）。不会将原始简历或身份字段写入 PaperPro 仓库或测试日志；脚本不加入日常离线 CI。

三轮实测均为 2026-10-19，严格复用相同 Git commit、相同 20 份 PDF、相同字段定义和分母：

字段明细是每个 GT 已标注实体的命中率，不能推成所有真实简历完整率。该独立数据的 workExperience 也可能包含校园社团职责，和本产品的工作/实习定义不同，必须澄清映射而不是为了分数硬塞入工作经历。

真实原因之一已由原版 PDF 脱敏版式确认：例如中英双语“工作经历 / Experience”“教育背景 / Education”，以及“2022.07—至今：数据库工程师：某公司”等职位在前、公司在后的行。相关识别逻辑已做最小修改，见 app/parser.py、app/diagnosis/adapter.py 与 tests/test_synthetic_parsing_quality.py。

前两轮改善较小。进一步分析 50 个职位标签的去向后发现：23 个职位已经出现在工作经历标题中，却未被填入 role 字段；其中多数是“公司 空格 职位”的写法。经保守切分后，同样 20 份 PDF 的职位命中由 1/50 → 14/50，总体增至 **156/276 = 56.52%**，相对首轮增加 20 个字段、7.24 个百分点。**仍未达到外部挑战集的 90% 门槛**。其他职位还散落在未分类段落、职责正文或原文本身缺失，需要后续分块/关系抽取机制，不应无限堆叠正则。

## 甲方演示步骤与验收口径

1. 首页上传 PDF/DOCX/DOC/PNG/JPG 或粘贴文本；验证格式限制、10MB 上限与加载反馈。
2. 在可编辑表单修正姓名、教育、工作公司、职位、起止年月、项目和证书；原文件 SHA256 不变。
3. 职位和公司两项都空则禁用生成按钮；填写至少一项后可继续。
4. 查看七类岗位要求的系数、有效权重、引用原文、总分、等级与 HR 视角边界说明。
5. 五维产出各自有证据和结论；关闭一维不影响其他维度。
6. 建议至少八项，每项有定位、问题或优化机会、建议和局部示例；高优先级只给可核对的过筛硬伤。
7. 勾选若干建议或面试核查条目，分别导出 TXT/PDF；未勾选的内容不会出现在文件中。
8. 报告提供时间、版本、规则版本；可选 DeepSeek 需要显式数据发送同意，模型无法改写规则算出的分数。
9. 移动端浏览器模拟完成选择与预览；其他两个智能体的 UI 与真实 iOS/Android 仍需独立验收。
10. 经典编辑器仍位于 /classic，settings.json 与私有 settings.local.json 正常。

## 结论分层（必须分别呈现）

- DEMO_PASS：R7–R10 的已实现产品功能，可现场操作和用 Chrome/Python 回归脚本验证。
- SYNTHETIC_PASS：20 份自行构造 DOCX/PDF 的 260/260 字段，四张高清模拟图片的 49/52 字段，1680 组反事实对照预期关系均成立。
- EXTERNAL_REFERENCE_BASELINE：固定 20 份外部合成 PDF 的结构化命中率三轮为 49.28% → 51.81% → **56.52%**；原文提取 92.39%；**仍未达到 90%**。
- NOT_VALIDATED：20 份真实自愿提供简历的统计准确率、真实手机拍摄与权限、美太内部评分细则、真实 HR 选拔结果、另外两个智能体风格统一。

推荐甲方描述：“PaperPro 的五步候选人诊断闭环已可演示；岗位评分可重复、可溯源，报告与清单可导出。外部多版式 PDF 结构解析及真实 HR 效度仍属后续专项验收。”

## 后续最小动作

双语标题、职位先行句式与公司名称后空格接职位的最小修复已按相同 20 份 PDF 严格重测。下一阶段需优先做复杂版式文本分块、关系提取，或经用户明确同意的模型辅助结构化纠偏，继续将 **56.52%** 作为新的固定回归基线，不修改独立 GT 的分母。
